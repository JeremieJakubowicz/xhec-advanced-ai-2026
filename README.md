# Advanced AI: Language Models & Agents — X-HEC, Fall 2026

Public material for the course. Everything runs on the free tier of Google Colab; no paid service and no account other than Google are needed.

## Sessions

| #   | folder      | topic                                                       | GPU |
| --- | ----------- | ----------------------------------------------------------- | --- |
| 1   | `Session1/` | Shannon, Markov models, the memorization trap, tokenization | no  |

Each session folder has its own README explaining how to run the notebooks, on Colab or locally.

## Data

`data/` holds the datasets the notebooks download by themselves. Currently: `hugotexts.txt`, works of Victor Hugo (14 MB, public domain, accents partly stripped by the digitisation).
