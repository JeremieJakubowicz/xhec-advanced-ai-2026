What the prediction can see

Four causal convolutions of kernel 3: the prediction after the selected token depends on that token and the eight before it, and on nothing else. Highlighted: its receptive field.

How much each layer writes

Each layer adds u ⊙ σ(g) to its input. The map shows the average gate σ(g) at every position: dark means the layer is writing a lot there.

LSTM 5.9 M parameters, two layers of 512 units

The forget gates

One row per memory slot, one column per token: how much of the slot is kept at that step (dark: kept, light: erased). A slot that stays dark across many tokens is carrying something over a long distance.

How far back does each model look?

Same prediction, after the selected token, but the models are only shown the last k tokens. The curve gives the probability they assign to the token that actually follows (or to their favourite token, if the selected one is the last).
