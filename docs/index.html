      0. From characters to tokens

      The tokenizer first cuts the text into pieces with a fixed rule (a regular expression: a word with the space before it, a number, a run of punctuation). Each piece is then turned into bytes, each byte into a printable character, and merges learned on the Hugo corpus are applied in order of priority until no merge applies. What remains are the tokens.

          2a. Through the CNN: the residual stream

          The stream starts as the embedding. Each layer reads the last three positions of the stream, computes a content u and a gate σ(g), and adds u ⊙ σ(g) to the stream. Watch how little a layer changes the stream, and where. After the last layer, LayerNorm rescales the stream into z, whose dot products with the 8,000 embeddings are the logits.

          2b. Through the LSTM: memory and gates

          Each layer receives an input x (the embedding for layer 1, the output of layer 1 for layer 2) and its own previous output ht−1 and memory ct−1. From x and ht−1 it computes the candidate and the three gates, then updates the memory and reads the output. The projection z of the last output is what meets the embeddings.

          3. The LSTM's memory over time

          The twelve memory slots of layer 2 with the largest values at the selected token, followed across the whole text. A flat line is a slot holding on to something; a jump is a write; a decay towards zero is the forget gate at work.
